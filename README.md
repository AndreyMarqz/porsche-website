## 📄 About The Project

This project is a concept landing page dedicated to the Porsche brand. It was developed as a personal study project to strengthen my frontend development fundamentals, specifically focusing on layout construction and styling.

The main goal was to replicate a modern design without relying on CSS frameworks (like Bootstrap or Tailwind), focusing entirely on writing raw, semantic HTML and custom CSS.

### 🎯 Learning Objectives
By building this project, I focused on mastering:
* **CSS Flexbox:** Managing layouts, alignment, and distribution of space.
* **Semantic HTML5:** Structuring the document correctly.
* **CSS Box Model:** Understanding padding, margins, borders, and content flow.
* **Asset Management:** Handling images and resources structure.
